# Resumatic

Tech stack:
- Firebase
- NextJS


Create high-quality, pixel-perfect resumes, every single time, even across content updates


## Decouples content from presentation
In Word, content is tightly coupled to formatting and presentation. Changes to content directly change the presentation as well. This becomes a hassle to manage as content evolves and changes

This project decouples content from presentation. It allows fearless changes in content. Formatting and presentation is guaranteed to stay consistent and stable across updates



## Consistency
Maintaining a consistency in Word (font sizes, spacing, colors, etc.) is a nightmare.

This system achieves a strong consistency in design


## Advanced Layouts
It can achieve sophisticated layouts (such as frameless tables, justified text, etc.) that are impossible in Word

## Advanced Typography
It can seamlessly switch between different font styles, font weights, font colors, etc. Again, without changing the presentation

## Tight Control over whitespaces
Easy to control all whitespaces and margins

## Profiles
It supports seamless management of resumes targetted for various profiles. Presentation stays consistent across all profiles
